# GamePlaytestHarness

Experimental 30 FPS reinforcement-learning controller for a user-owned game test environment.

## Feedback
- GREEN = good (+1)
- ORANGE = useful but too slow (0; increase action speed)
- RED = bad (-1)

The agent is intentionally not given semantic game knowledge. It selects low-level keyboard/mouse actions and learns from visual feedback.

## Safety
Designed for controlled testing in an owned/custom game environment, not for automating public Fortnite matches.
